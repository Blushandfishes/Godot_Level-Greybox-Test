# Pixel Platformer Tileset Vol. 2 (16x16)
134 sprites by reodesuxz. Sequel to Pixel Forest Platformer Tileset (Vol. 1): https://reodesuxz.itch.io/free-pixel-forest-platformer-tileset-16x16
- 4 new terrain biomes: Cave, Lava/Volcanic, Sky Islands (cloud blocks), Ancient Ruins. Each: 3x3 auto-tile set, fill variant, single block, 3-tile one-way platform
- Lava liquid (2-frame surface, fill, lavafall), cave & ruins background walls
- Hazards: spikes (4 directions), saw blade, fireball, falling stalactite
- Gadgets: spring (2 frames), lever on/off, button, checkpoint off/on, ? block, used block, crumbling block, metal crate
- Moving platforms (metal + cloud, 3-piece) and chain; ladders, rope, vine; doors (closed/open/locked, 32x32) + exit sign
- Collectibles: 4-frame spinning coin, gems, key, star, heart; biome decor for each zone
Files: PNG/native + PNG/x4 (nearest), tileset.png, spritesheet.png + spritesheet.json, sample_level.png, animations/ (sheets + GIF previews)
Unity/Godot/GameMaker: Filter Mode = Point / Nearest, Compression = None, pixels-per-unit 16.
