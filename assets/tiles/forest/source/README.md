# Pixel Forest Platformer Tileset (16x16)
102 sprites by reodesuxz: 4 terrain themes (grass, stone, sand, snow) as 3x3 auto-tile sets + fills + single blocks + 3-tile platforms, trees, bushes, flowers, mushrooms, rocks, props, pickups, hazards, clouds and sun.
- PNG/native (16x16 tiles; trees/bushes/clouds larger) and PNG/x4 (nearest-neighbour)
- tileset.png (all terrain + platform tiles), spritesheet.png + spritesheet.json, sample_scene.png
Unity/Godot/GameMaker: Filter Mode = Point / Nearest, Compression = None, pixels-per-unit 16.
