# Pixel Platformer Tileset Vol. 3 (16x16)
151 sprites by reodesuxz. Same grid and style as Vol. 1 and Vol. 2.
- 4 new terrain biomes: Castle (stone brick), Swamp (mud + toxic water), Ice / Snow, Desert (sandstone). Each: 3x3 auto-tile set, fill variant, single block, 3-tile one-way platform
- Swamp water (2-frame surface, fill), castle and swamp background walls
- Hazards, gadgets (spring, lever, button, checkpoint, ? block, crates), moving platforms, ladders, rope, vine, doors (32x32), collectibles incl. 4-frame coin
- Biome decor: castle (banners, throne, cannon, armor, chandelier, skeleton...), swamp (dead tree, frog, lily pad, toadstool...), ice (snowman, igloo, penguin, icicle...), desert (cactus, palm, scarab, pyramid...)
Files: PNG/native + PNG/x4 (nearest), tileset.png, spritesheet.png + spritesheet.json, sample_level.png, animations/
Unity/Godot/GameMaker: Filter Mode = Point / Nearest, Compression = None, pixels-per-unit 16.
